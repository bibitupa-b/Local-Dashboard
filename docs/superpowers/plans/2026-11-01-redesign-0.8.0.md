# Global Redesign 0.8.0 — Implementation Plan

> **For agentic workers:** implement task by task. Steps use `- [ ]`. Each task ends with a passing build/test run and a commit.

**Goal:** Replace the light UI with the dark "quiet instrument" design from `DESIGN.md`: canonical palette, mono metadata, restrained motion, accessible dialogs and hints. No new features.

**Architecture:** Restyle in place. `src/web/styles.css` becomes the token+component layer; `App.tsx` and `Settings.tsx` get the markup changes the design requires (primary button, banner variants, skeleton, confirm dialog, hint ARIA, animated diff). Electron window background follows the palette.

**Tech Stack:** React 19, Vite, plain CSS, no animation libraries.

**Spec:** `DESIGN.md` (authoritative; palette and motion tables must not be extended without editing it).

## Global Constraints

- Dark only. No theme toggle, no light fallback.
- Only the ten palette colors plus Lichen and Void (§3.1). No unlisted hex in CSS.
- Motion: `transform`, `opacity`, `filter` only; width allowed for the 3px sync bar and the diff grid wrapper.
- All interactive motion finishes within 320 ms; only ambient loops are slower.
- At most two infinite animations per screen; loops pause when `document.hidden`.
- Entrance animation only on first mount; the 60 s refresh must not re-animate or shift layout.
- Full `prefers-reduced-motion` block; every state remains readable without motion.
- Keep class names: `page card pill today event suggest result diff note modal conn-row`.
- No new dependencies, no JS animation library, no decorative images.

## Risks

- **Contrast:** Clay on Slate is 3.87 — error text must live on Graphite/Obsidian.
- **Focus trap:** hand-written; verify Tab/Shift+Tab and focus return.
- **Clipping:** hint tooltips inside scrolling cards may clip; fall back to fixed positioning.
- **Motion budget:** two infinite loops max; the briefing glow and modal rings must not coexist.
- **Refresh flicker:** entrance animations keyed off mount ref, not CSS on data updates.
- **Tests:** jsdom has no layout; animations are asserted via presence/classes, not computed styles.
