# Local Dashboard 1.13.0

**One quiet screen: where to start today, what happened, and one briefing.**

1.13.0 starts Phase 3 with three sources that make the morning brief less about work alone.

## Highlights

- **Weather** — today's temperature range, conditions and rain chance from Open-Meteo. Only
  latitude and longitude are needed; there is no API key and no account.
- **RSS / News** — one or more RSS/Atom feeds, parsed on your machine. The briefing sees only
  titles and short summaries.
- **Google Tasks** — the Google connection now requests `tasks.readonly`; due tasks appear in the
  briefing and in "Start here" as `google-task` items. Reconnect Google once to grant the scope.
- **Google Tasks API** is named in the connection hint. A token without the scope is harmless; the
  app simply has no task source.
- The only new dependency is `fast-xml-parser`, used by the RSS reader.

## Install

1. Download `Local-Dashboard-Setup-1.13.0.exe` below and run it.
2. SmartScreen may warn because the build is not code-signed: **More info → Run anyway**.
3. Connect a vault, add a DeepSeek key, and optionally add weather, RSS or Google Tasks.

`Local-Dashboard-1.13.0.exe` is the portable build.

## Privacy

The app remains read-only toward every service. Weather sends coordinates to Open-Meteo; RSS fetches
the feed URLs you configure. Only a compact digest goes to DeepSeek, and only when a briefing is
generated. Whole notes, full mail bodies, attachments, browser URLs, page titles, tokens and
passwords are never sent. No telemetry, no analytics.
