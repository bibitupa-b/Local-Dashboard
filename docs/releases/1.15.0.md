# Local Dashboard 1.15.0

**One quiet screen: where to start today, what happened, and one briefing.**

1.15.0 makes the whole dashboard optional. It opens with no connection and no DeepSeek key, can be
told to stay entirely offline, and reads Apple calendars through CalDAV.

## Highlights

- **Everything is optional** — a fresh install is a valid state. The dashboard loads, a dismissible
  card says what can be added, and the briefing uses local rules and labels itself `rules` instead
  of failing without a DeepSeek key.
- **Local only** — a Settings toggle and a topbar badge block every outbound request, including
  DeepSeek, weather, RSS, Slack, CalDAV, Gmail, GitHub and Google. Vault and browser history keep
  syncing, and data already fetched stays visible; the topbar marks Local only.
- **Apple and generic CalDAV** — a read-only calendar source through `tsdav` and `ical.js`. Pick
  the iCloud preset with an app-specific password, or any CalDAV server with URL, username and
  password. Events appear beside the Google calendar and reuse the same calendar source and table.
- **Recurring events** — RRULE/EXDATE instances expand inside the configured window, capped at 100
  per event; all-day events keep their calendar day and timezones land on the right day.
- **One bad calendar does not hide the rest** — a malformed event or unreachable calendar is logged
  and skipped while the others still sync.
- **Credentials stay encrypted** — the CalDAV password is stored with AES-256-GCM via `SecretBox`,
  like every other connection secret.

## Install

1. Download `Local-Dashboard-Setup-1.15.0.exe` below and run it.
2. SmartScreen may warn because the build is not code-signed: **More info → Run anyway**.
3. Start the app. Nothing is required; connect a vault or CalDAV calendar when you want one, and add
   a DeepSeek key only for the written briefing.

`Local-Dashboard-1.15.0.exe` is the portable build.

Upgrading from 1.14.0 keeps the database and connections. Local only defaults to off.

## Privacy

The app is read-only toward every service. Local only blocks all outbound calls, including the
briefing, weather, RSS, Slack, CalDAV, Gmail, GitHub and Google; only the local vault and browser
history continue. CalDAV credentials are encrypted and used only against the server you configured.
Otherwise only a compact digest goes to DeepSeek, and only when a briefing is generated. No
telemetry, no analytics.

## Known limits

- The installer is not code-signed.
- CalDAV syncs on the normal schedule; there is no push or IMAP-style IDLE for calendars yet.
- Recurring expansion caps at 100 instances per event in the window.
- Microsoft 365, IMAP IDLE and SMTP/Telegram delivery remain in later releases.
- Auto-update, e2e and visual regression are still Phase 4.
