# Local Dashboard 1.12.0

**One quiet screen: where to start today, what happened, and one briefing.**

1.12.0 is the gap-closure release: the briefing and the start line now tell the truth more often,
and the local data controls are real.

## Highlights

- **Reply triage survives reading.** "Awaiting your reply" includes read mail and closes on a sent
  reply, using `References` / `In-Reply-To` with a subject fallback.
- **Attention is separate from activity.** Browser visits and Drive changes moved to
  `/api/activity`; a quiet day no longer answers "Start here" with a visit count.
- **Sources actually filter.** Disabling mail, vault, Drive, calendar, browser or GitHub removes
  its items from attention, the briefing and search.
- **Daily and weekly no longer collide.** Daily catch-up looks at `kind = 'daily'`; weekly review
  catches up on startup once a daily history exists; `briefingToday` means daily.
- **FTS5 search with Unicode.** Cyrillic is case-insensitive; `/api/search` accepts `source`,
  `from` and `to`; a `LIKE` fallback keeps older databases working.
- **Per-point feedback.** Every briefing point has its own Useful/Miss, stored in
  `briefing_feedback` and fed back into the prompt.
- **Calendar depth.** Multiple Google calendars per connection and configurable work hours for free
  windows.
- **Local data controls.** Export a secret-free JSON snapshot, delete indexed data, and set
  retention for mail bodies, browser visits and vault diffs.
- **Meeting prep.** A 30-minute heads-up, separate from the 15-minute "starting soon" alert.
- **Honest labels.** Rules briefings say `rules`; a failed strict-grounding check says `unverified`.

## Install

1. Download `Local-Dashboard-Setup-1.12.0.exe` below and run it.
2. The build is not code-signed, so SmartScreen may ask you to confirm the publisher:
   **More info → Run anyway**.
3. Start the app and connect at least one source. The dashboard shows a **Get started** checklist
   until a vault and a DeepSeek key are in place.

`Local-Dashboard-1.12.0.exe` is the portable build.

Data lives in `%APPDATA%\Local Dashboard\data`. Backups are taken daily into
`data/backups/` and kept for seven days; `data/secret.key` is not in the backup, so copy it
separately if you want to restore encrypted connection secrets on another machine.

## Privacy

The app is read-only toward every service. Only a compact digest leaves the machine, and only when
a briefing is generated. It contains note paths and short excerpts, task titles, project names,
Drive file names, today's calendar, unread mail subjects/senders and the first ~200 characters of
unread mail. Whole notes, full mail bodies, attachments, browser URLs, page titles, OAuth tokens and
passwords are never sent. There is no telemetry and no analytics.
