# Local Dashboard 1.14.0

**One quiet screen: where to start today, what happened, and one briefing.**

1.14.0 adds Slack to the morning screen: mentions and DMs become one actionable row, without
putting message text into the briefing.

## Highlights

- **Slack attention** — a user or bot token reads mentions and DMs from the last 24 hours. The
  dashboard shows `Slack: N mentions` with the channel names; the briefing sees the count and
  channels, never the message text.
- **Slack connection** — Settings asks for a token with read history scopes and offers an optional
  user id for bot tokens. **Test** calls `auth.test`.
- **Health and receipts** — Slack follows the same last-sync/error path as the other sources.
- No message bodies go to DeepSeek; only channel names and counts.

## Install

1. Download `Local-Dashboard-Setup-1.14.0.exe` below and run it.
2. SmartScreen may warn because the build is not code-signed: **More info → Run anyway**.
3. Connect a vault, add a DeepSeek key, and optionally add Slack.

`Local-Dashboard-1.14.0.exe` is the portable build.

## Privacy

The app is read-only toward every service. Slack message text stays in the local database for the
current sync window and is never part of the digest; only channel names and mention counts leave the
machine. Weather coordinates go only to Open-Meteo; RSS feeds are fetched directly. Only a compact
digest goes to DeepSeek, and only when a briefing is generated. No telemetry, no analytics.
